English: [README.md](README.md) · Español: [README.es.md](README.es.md)

O cashback de taxas devolve parte do que você paga. Mas ele é um percentual das taxas, então um percentual maior numa exchange mais cara ainda pode custar mais. Estas tabelas ordenam as exchanges pelo **custo líquido**: taxas menos cashback, no nível que o seu volume mensal alcança. Todas as ordens como taker.
